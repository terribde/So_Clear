# 清如许 SoClear

面向学生的教师评价与课程查询站点。当前已进入首个可运行版本：公开教师/课程查询前端、本地公开 API 与共享契约已落地，全部数据为合成演示数据。

产品原则：教学资料与学生主观评价分开呈现；四维正向评分；少于 5 条公开评价不显示综合分；评价匿名展示、人工审核；不设积分、签到或 AI 扣分。学生自带模型（BYOK）与同站管理区仍在后续阶段。

## 已实现（P1 公开查询）

- 响应式站点：首页、教师库、教师详情、课程与开课、评价方法、我的（待接入说明）、学生 AI 规划页。
- 四维评分：讲授清晰度、课程组织、反馈支持、考核透明度；服务端计算，少于 5 条只显示样本量。
- 教师搜索：关键词、学院、本学期筛选与稳定排序；签名游标分页与筛选绑定。
- 教师详情：四维雷达、公开评价、平台摘要的 `ready / insufficient / generating / unavailable` 状态、本学期开课。
- 课程查询：本学期教学班、学院/校区/日期筛选、确定性四维偏好排序、选课号复制。
- 公开 API 白名单：不返回作者、审核人、审核状态、驳回原因等管理字段；所有查询响应 `no-store`。
- 合成数据：16 位教师、12 门课程、24 个本学期教学班、79 条公开评价，明确标注为演示数据。

尚未实现：独立平台账号、匿名学生认证、评价提交/审核/撤回/申诉、真实平台 AI 生成、Supabase 持久化、`/admin` 权限与管理面板、缓存与生产部署。界面中这些入口均明确标记为未开放，不提供虚假表单或试用。

## 本地运行

要求 Node.js ≥ 22、pnpm 12。

```bash
pnpm install
pnpm dev        # API: 127.0.0.1:8787  站点: localhost:5173
pnpm test       # 12 项评分、DTO、游标与公开接口测试
pnpm typecheck
pnpm build
```

站点通过 Vite 代理访问 `/api`，浏览器只与本站同源 API 通信，不连接数据库。

## 数据与安全边界

- 本版本没有登录、Cookie 会话、学生认证、数据库或模型密钥。
- 公开响应由 DTO 白名单映射生成；内部审核字段不会经 API 输出。
- 游标使用 HMAC 签名并绑定当前筛选条件，校验失败或跨筛选复用返回 `CURSOR_INVALID`。
- 未知查询参数、未知学院/学期返回受控 `422`；不存在资源返回 `404`。
- 前端不写入 localStorage / IndexedDB，不使用 `dangerouslySetInnerHTML`，不请求第三方来源。
- 生产上线前仍需完成架构文档要求的身份、RLS/最小权限、CSP、限流、缓存、审计、压测与恢复演练；原型通过不代表这些门槛已满足。
